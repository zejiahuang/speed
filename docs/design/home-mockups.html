首页美化 · 三版对比

三版结构完全相同（顶部一行标题+模式 chip / 168dp 圆形按钮 / 状态 / 一张速率卡含底部总流量 / 底部导航）， 差别只在材质与层次。所以挑的时候只需要问自己一句：哪一种看起来最像「我想每天打开的那个东西」。 按钮与数字都按已连接态绘制（这样才能看出渐变、光环和数字的表现）。

三版都一样的部分（不用挑）： ① 顶部 speed 缩小、VPN 模式 做成 chip 挪到同一行，省下的垂直空间全部给按钮； ② 速率卡左列下行 / 右列上行，卡底一行「本次总流量」，数字用等宽数字避免跳动； ③ 规则源卡移到规则页，命中率卡与开发者明细移到日志页； ④ 已连接时按钮持续呼吸光环、卡片依次入场、切页淡入 + 上移 8dp、底部导航选中项弹性缩放； ⑤ 配色不动，只把状态色语义理顺（已连接=主题色 / 未连接=中性灰 / 启动中=降饱和 / 失败=错误色）。

另外两点说明： 「未连接」态下按钮一律是中性灰、无光环、数字为 0 B/s —— 三版都如此，只是灰色的深浅和投影不同。 想混搭也可以直接说（例如「A 的按钮 + C 的速率卡」），我按你说的组合做。
